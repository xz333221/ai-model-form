## ai-model-form：新增发布脚本 scripts/release.js

参考 zen-gitsync 的 `scripts/release.js` 改写（同结构，按「库」而非「CLI」调整），617 行、零依赖（内置 ANSI 颜色，不引 chalk）：

8 步流程：环境检查(含 npm whoami) → 版本号 patch+1 → `npm run build` → dist 产物校验 → `npm pack` 预检 → commit/tag/push → publish → 线上版本轮询校验。

- 参数：`--dry-run / --skip-push / --skip-build / --minor / --major / --version=x.y.z / --yes / --help`
- 护栏：版本号已存在则报错；dist 比源码旧（忘构建）报错；staged 超出白名单中止；构建失败在改 git 前就能中止
- 发布内容固定 7 文件（files 字段），脚本会校验 tarball 必须含 dist/*3 + server/middleware.js 且不得混入 client/ demo/ scripts/ 等
- git 命令一律 `spawnSync/spawn` + args 数组 → Windows 中文 commit message 不乱码；保留 zen-gitsync 的 git 锁清理与按 PID 精准 kill
- package.json 加了 `"release": "node ./scripts/release.js"`
